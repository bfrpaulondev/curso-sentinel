## Termos desta aula

- **Log Analytics workspace** — O 'armazém' onde os logs ficam guardados e são consultados com KQL.
- **Microsoft Sentinel** — SIEM e SOAR que funciona por cima de um workspace.
- **Limite diário (daily cap)** — Teto de GB por dia que o workspace aceita ingerir.

## Laboratório guiado

Todos os comandos rodam a partir da pasta raiz do [repositório do curso](https://github.com/bfrpaulondev/curso-sentinel).

### Passo 1

Valide o template do workspace + Sentinel.

```bash
bicep lint labs/m0/sentinel.bicep && echo 'sem avisos'
```

**Saída esperada** (execução real):

```text
sem avisos
```

### Passo 2

Liste os tipos de recurso do template.

```bash
bicep build labs/m0/sentinel.bicep --stdout | grep '"type"'
```

**Saída esperada** (execução real):

```text
      "type": "string",
      "type": "string",
      "type": "Microsoft.OperationalInsights/workspaces",
      "type": "Microsoft.SecurityInsights/onboardingStates",
      "type": "string",
```

### Passo 3

Na sua conta: crie o grupo e faça o deploy.

```bash
az group create -n rg-curso-sentinel -l brazilsouth
az deployment group create -g rg-curso-sentinel -f labs/m0/sentinel.bicep
```

:::note[Precisa da sua conta]
Precisa de login no Azure.
:::
