## Termos desta aula

- **Subscrição** — A 'conta de luz' do Azure: tudo o que você cria é cobrado nela.
- **Orçamento (Budget)** — Um limite de referência mensal que dispara alertas. Ele avisa, mas NÃO desliga nada.
- **Bicep** — Linguagem da Microsoft para descrever recursos do Azure como código.

## Laboratório guiado

Todos os comandos rodam a partir da pasta raiz do [repositório do curso](https://github.com/bfrpaulondev/curso-sentinel).

### Passo 1

Abra o arquivo do orçamento no VS Code.

```bash
code labs/m0/orcamento.bicep
```

### Passo 2

Valide o Bicep localmente (não precisa de conta).

```bash
bicep lint labs/m0/orcamento.bicep && echo 'sem avisos'
```

**Saída esperada** (execução real):

```text
sem avisos
```

### Passo 3

Gere o template ARM para ver o que o Azure vai receber.

```bash
bicep build labs/m0/orcamento.bicep --stdout | head -12
```

**Saída esperada** (execução real):

```text
{
  "$schema": "https://schema.management.azure.com/schemas/2018-05-01/subscriptionDeploymentTemplate.json#",
  "contentVersion": "1.0.0.0",
  "metadata": {
    "_generator": {
      "name": "bicep",
      "version": "0.48.1.52935",
      "templateHash": "2041619382135466602"
    }
  },
  "parameters": {
    "email": {
```

### Passo 4

Na sua máquina, com a sua conta: entre e aplique. Troque o e-mail.

```bash
az login
az deployment sub create -l brazilsouth -f labs/m0/orcamento.bicep -p email=voce@exemplo.com
```

:::note[Precisa da sua conta]
Precisa de login no Azure. Confira depois em Cost Management → Budgets.
:::
