## Termos desta aula

- **Kustainer** — Emulador oficial do Kusto em Docker: roda KQL de verdade, sem conta.
- **Azure CLI (az)** — Linha de comando para gerenciar o Azure.
- **Git** — Histórico de versões do seu código — inclusive das regras de detecção.

## Laboratório guiado

Todos os comandos rodam a partir da pasta raiz do [repositório do curso](https://github.com/bfrpaulondev/curso-sentinel).

### Passo 1

Suba o emulador Kusto e carregue o dataset da Loja Pixel (sem conta).

```bash
cd labs/m0 && ./0.local_setup.sh
```

### Passo 2

Confira as ferramentas.

```bash
git --version && az version | head -3
```

**Saída esperada** (execução real):

```text
git version 2.47.3
{
  "azure-cli": "2.92.0",
  "azure-cli-core": "2.92.0",
```

### Passo 3

Primeira consulta real.

```bash
./kql.py 'union withsource=Tabela SigninLogs, LojaApi_CL, Syslog | summarize Linhas=count() by Tabela'
```

**Saída esperada** (execução real):

```text
Tabela     | Linhas
-----------+-------
Syslog     | 535   
SigninLogs | 933   
LojaApi_CL | 2540  

(3 linhas)
```
