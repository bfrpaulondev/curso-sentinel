## Termos desta aula

- **API** — O 'balcão' da loja: recebe pedidos (HTTP) e devolve respostas.
- **Log em JSON** — Cada linha é um objeto JSON — fácil de ingerir e de ler com parse_json.
- **X-Forwarded-For** — Cabeçalho que informa o IP original do cliente quando há um proxy no meio.

## Laboratório guiado

Todos os comandos rodam a partir da pasta raiz do [repositório do curso](https://github.com/bfrpaulondev/curso-sentinel).

### Passo 1

Suba a API da Loja Pixel.

```bash
node api-loja/server.js &
```

### Passo 2

Faça um login com senha errada.

```bash
curl -s -X POST localhost:3000/api/login -H 'Content-Type: application/json' -d '{"email":"carla@cliente.com","senha":"errada"}'
```

**Saída esperada** (execução real):

```text
{"erro":"credenciais inválidas"}
```

### Passo 3

Veja o log gerado (formato LojaApi_CL).

```bash
tail -n 1 api-loja/logs/api.jsonl
```

**Saída esperada** (execução real):

```text
{"TimeGenerated":"2026-11-03T16:18:26.603Z","Service":"api-loja","Method":"POST","Route":"/api/login","StatusCode":401,"DurationMs":1,"ClientIP":"::1","Properties":{"userAgent":"curl/8.14.1","region":"local-lab","tags":["web"],"login":"carla@cliente.com"}}
```

### Passo 4

Opcional, na sua conta: deploy completo no Azure (custa dinheiro — apague no fim).

```bash
cd labs/m0 && ./0.3_deploy_loja.sh
```

:::note[Precisa da sua conta]
Precisa de login no Azure e de permissão para criar usuários no Entra ID.
:::
