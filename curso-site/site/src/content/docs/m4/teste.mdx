## Parte 2 — Teste prático: a sua regra tem de gerar um incidente

Escreva a sua regra (YAML) para a força bruta na API. Rode `python3 grader/testar_regra.py minha_regra.yaml`: o script ataca a API local a partir de um IP aleatório, envia os logs para o Kusto, roda a sua regra no simulador e só aprova se surgir um incidente com a entidade IP do atacante. Cole aqui a saída para registrar a aprovação.
