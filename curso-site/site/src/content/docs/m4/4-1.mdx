## Termos desta aula

- **Regra agendada (Scheduled)** — Uma query KQL que roda de tempos em tempos e gera alertas.
- **NRT** — Near-real-time: roda a cada minuto.
- **Fusion** — Correlação de ataques em várias etapas feita pela Microsoft.

:::caution
O motor_regras_local.py é um SIMULADOR didático: valida o YAML no formato do repositório Azure-Sentinel, roda a query no Kusto real e aplica limiar e agrupamento. Ele NÃO é o Microsoft Sentinel.
:::

## Laboratório guiado

Todos os comandos rodam a partir da pasta raiz do [repositório do curso](https://github.com/bfrpaulondev/curso-sentinel).

### Passo 1

Suba a API e rode o ataque (só localhost).

```bash
node api-loja/server.js &
bash labs/m4/ataque_forca_bruta.sh | tail -4
```

**Saída esperada** (execução real):

```text
monkey -> 401
1q2w3e -> 401
senhaforte -> 401
Senha#Forte2026 -> 200
```

### Passo 2

Envie os logs ao Kusto.

```bash
python3 labs/m4/enviar_logs.py
```

**Saída esperada** (execução real):

```text
21 eventos enviados para LojaApi_CL
```

### Passo 3

Rode a query da regra.

```bash
./kql.py 'LojaApi_CL | where TimeGenerated > ago(15m) and Route == "/api/login" | summarize Falhas=countif(StatusCode==401), Sucessos=countif(StatusCode==200) by ClientIP'
```

**Saída esperada** (execução real):

```text
ClientIP     | Falhas | Sucessos
-------------+--------+---------
203.0.113.66 | 20     | 1       

(1 linha)
```
