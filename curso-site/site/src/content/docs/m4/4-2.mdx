## Termos desta aula

- **Entidade** — Um 'personagem' do alerta: IP, conta, host…
- **Identificador** — O campo que identifica a entidade (ex.: Address do IP).
- **Custom details** — Campos da query que aparecem direto no alerta.

:::caution
O motor_regras_local.py é um SIMULADOR didático: valida o YAML no formato do repositório Azure-Sentinel, roda a query no Kusto real e aplica limiar e agrupamento. Ele NÃO é o Microsoft Sentinel.
:::

## Laboratório guiado

Todos os comandos rodam a partir da pasta raiz do [repositório do curso](https://github.com/bfrpaulondev/curso-sentinel).

### Passo 1

Rode a regra no simulador local.

```bash
python3 labs/m4/motor_regras_local.py labs/m4/regras/forca_bruta_api.yaml
```

**Saída esperada** (execução real):

```text

▶ Regra: Loja Pixel - Força bruta na API de login  [Scheduled, a cada 5m, olhando 15m]
  ✓ YAML válido • MITRE: CredentialAccess / T1110
  ⚠ 1 alerta(s)
  [INCIDENTE] INC-C3EFA0: 1 alerta(s) • entidades: IP=203.0.113.66

Total: 1 incidente(s) → incidentes.json
```

### Passo 2

Inspecione entidades e detalhes.

```bash
python3 -m json.tool labs/m4/incidentes.json | head -30
```

**Saída esperada** (execução real):

```text
[]
```
