## Termos desta aula

- **Falso positivo** — Alerta que dispara sem ataque de verdade.
- **Limiar** — O número a partir do qual a regra dispara.
- **Lista de exceções** — IPs ou contas conhecidos que não devem alertar.

:::caution
O motor_regras_local.py é um SIMULADOR didático: valida o YAML no formato do repositório Azure-Sentinel, roda a query no Kusto real e aplica limiar e agrupamento. Ele NÃO é o Microsoft Sentinel.
:::

## Laboratório guiado

Todos os comandos rodam a partir da pasta raiz do [repositório do curso](https://github.com/bfrpaulondev/curso-sentinel).

### Passo 1

Meça o comportamento normal.

```bash
./kql.py 'LojaApi_CL | where Route == "/api/login" and StatusCode == 401 | summarize Falhas=count() by ClientIP | summarize p99=percentile(Falhas, 99), maximo=max(Falhas)'
```

**Saída esperada** (execução real):

```text
p99 | maximo
----+-------
138 | 138   

(1 linha)
```

### Passo 2

Prove que a regra ajustada ainda detecta.

```bash
python3 grader/testar_regra.py labs/m4/exemplos/forca_bruta_ajustada.yaml | tail -6
```

**Saída esperada** (execução real):

```text
  [INCIDENTE] INC-CBFF62: 1 alerta(s) • entidades: IP=203.0.113.66
  [INCIDENTE] INC-209379: 1 alerta(s) • entidades: IP=203.0.113.161

Total: 3 incidente(s) → incidentes.json

✓ APROVADO: a regra gerou um incidente com a entidade IP do atacante.
```
