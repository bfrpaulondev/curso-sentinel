## Termos desta aula

- **Função (let)** — Uma 'stored procedure' leve, definida na própria consulta.
- **invoke** — Chama uma função passando a tabela da esteira.
- **Filtro de tempo** — Limitar TimeGenerated primeiro é a otimização nº 1.

## Laboratório guiado

Todos os comandos rodam a partir da pasta raiz do [repositório do curso](https://github.com/bfrpaulondev/curso-sentinel).

### Passo 1

Use a função com invoke.

```bash
./kql.py -f labs/m2/2.5_funcoes.kql
```

**Saída esperada** (execução real):

```text
IPAddress     | Falhas
--------------+-------
198.51.100.23 | 32    

(1 linha)
```

### Passo 2

Provoque o erro de nome de coluna e leia a mensagem.

```bash
./kql.py 'SigninLogs | where resulttype != "0" | count'
```

**Saída esperada** (execução real):

```text
ERRO do Kusto: Semantic error: SEM0100: 'where' operator: Failed to resolve column or scalar expression named 'resulttype'
```
