## Termos desta aula

- **parse** — Recorta um texto usando pedaços fixos como molde.
- **extract()** — Tira um pedaço do texto com uma expressão regular.
- **mv-expand** — Transforma uma lista numa linha por item.

## Laboratório guiado

Todos os comandos rodam a partir da pasta raiz do [repositório do curso](https://github.com/bfrpaulondev/curso-sentinel).

### Passo 1

Recorte a mensagem do SSH.

```bash
./kql.py -f labs/m2/2.4_parse.kql
```

**Saída esperada** (execução real):

```text
Usuario | IP          | Tentativas
--------+-------------+-----------
admin   | 192.0.2.150 | 35        

(1 linha)
```

### Passo 2

Abra o JSON da API.

```bash
./kql.py -f labs/m2/2.4b_json_mvexpand.kql
```

**Saída esperada** (execução real):

```text
Tag          | Pedidos
-------------+--------
web          | 1040   
mobile       | 932    
promo        | 903    
black-friday | 902    

(4 linhas)
```
