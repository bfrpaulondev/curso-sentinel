Ataque → detecção → resposta

Na madrugada de 21/10/2026 a Loja Pixel sofre um password spray, um credential stuffing na API e força bruta no SSH. Você vai achar cada um com KQL.

KQL rodando de verdade

Todas as consultas foram executadas num Kusto real (emulador oficial Kustainer). Você roda o mesmo na sua máquina, sem conta.

Detecção como código

Regras em YAML no formato do repositório Azure-Sentinel, versionadas no Git e testadas com um ataque controlado.
